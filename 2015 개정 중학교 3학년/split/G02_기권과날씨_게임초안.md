# 게임 초안: 구름 항해사 (Cloud Navigator)
## 중학교 3학년 과학 - 2단원: 기권과 날씨

### 1. 개요
* **장르:** 2D 횡스크롤 탐험 + 전략
* **대상:** 중학교 3학년
* **핵심 컨셉:** 비행정을 타고 기권을 탐험하며, 고도에 따른 기온 변화를 측정하고 구름과 날씨를 예측하여 안전한 항로를 확보하는 게임

### 2. 학습 목표 (출판사 공통 참고)
* 기권의 층상 구조(대류권, 성층권, 중간권, 열권)와 특징 이해
* 복사 평형과 온실 효과의 원리 학습
* 상대 습도, 노점, 포화 수증기량의 관계 계산
* 구름의 생성 과정과 강수 이론(빙정설, 병합설)
* 기압과 바람의 발생 원리 및 전선과 기단

### 3. 주요 게임 메커니즘
* **기상 관측 위젯:** 실시간으로 현재 위치의 기온, 습도, 기압 정보를 확인하여 다음 행동 결정
* **구름 생성기:** 수증기를 응결시켜 구름을 만들고 비를 내려 지상의 불을 끄거나 장애물을 제거하는 퍼즐
* **일기예보 대시보드:** 등압선 지도를 보고 고기압과 저기압 위치를 파악하여 바람의 방향을 이용해 비행정 가속

### 4. 레벨 디자인 (퀘스트)
* **Quest 1: 하늘의 층계** - 대류권부터 열권까지 상승하며 각 층의 특징을 맞추는 퀴즈 통과하기
* **Quest 2: 습도 조절 대작전** - 실내 습도를 맞춰 곰팡이를 제거하거나 정전기를 방지하는 미니 게임
* **Quest 3: 태풍 추적자** - 기단과 전선(한랭/온난)의 이동을 예측하여 마을을 태풍으로부터 대피시키기

### 5. 참고 자료
* 비상/미래엔/동아/천재 2단원: 기권과 날씨
