# 게임 초안: 뉴로 디텍티브 (Neuro Detective)
## 중학교 3학년 과학 - 4단원: 자극과 반응

### 1. 개요
* **장르:** 2D 탐색 + 포인트 앤 클릭
* **대상:** 중학교 3학년
* **핵심 컨셉:** 신체 내부를 탐험하는 나노 로봇 조종사가 되어, 자극이 뇌까지 전달되고 다시 반응이 나타나는 경로를 따라가며 고장 난 감각 기관과 신경계를 수리하는 게임

### 2. 학습 목표 (출판사 공통 참고)
* 감각 기관(눈, 귀, 코, 혀, 피부)의 구조와 기능 이해
* 뉴런의 구조와 자극의 전달 경로 학습
* 중추 신경계(뇌, 척수)와 말초 신경계의 역할
* 항상성 유지를 위한 호르몬의 작용 (혈당량, 체온, 체액 농도 조절)

### 3. 주요 게임 메커니즘
* **신경 전달 퍼즐:** 끊어진 시냅스를 연결하여 전기 신호(자극)가 올바른 방향으로 흐르도록 배치
* **감각 매칭 게임:** 빛, 소리, 냄새 등 외부 자극에 맞는 감각 세포를 활성화시켜 올바른 인식 유도
* **호르몬 밸런서:** 혈당이 높거나 낮을 때 인슐린과 글루카곤 아이템을 적절히 투여하여 항상성 맞추기

### 4. 레벨 디자인 (퀘스트)
* **Quest 1: 어둠 속의 눈** - 눈의 구조(수정체, 홍채 등)를 조절하여 물체를 선명하게 보이게 하기
* **Quest 2: 뜨거운 냄비 반응** - 뜨거운 것을 만졌을 때 무의식적으로 손을 떼는 '반사' 경로를 따라 신속하게 신호 전달하기
* **Quest 3: 거인의 당뇨병** - 호르몬 불균형으로 쓰러진 거인의 혈당을 인슐린과 글루카곤으로 조절하여 깨우기

### 5. 참고 자료
* 비상/미래엔/동아/천재 4단원: 자극과 반응
